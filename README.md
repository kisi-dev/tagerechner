## Tagerechner

Ein kleines Python-Programm, das Jahre, Monate und Tage in eine
Gesamtzahl an Tagen umrechnet.

## Funktionen
- Abfrage von Jahren, Monaten und Tagen
- Berechnung über eine eigene Funktion
- Ausgabe mit deutschem Tausenderpunkt (z. B. 10.950)
- Farbige, umrahmte Ergebnisanzeige in der Konsole

## Hinweis zur Genauigkeit
Das Programm rechnet mit 365 Tagen pro Jahr und 30 Tagen pro Monat.
Schaltjahre und unterschiedlich lange Monate werden nicht berücksichtigt,
das Ergebnis ist also ein Näherungswert.

## Starten
Python 3 installieren und im Terminal ausführen:

    python tagerechner_v0.1.py

## Geplant
